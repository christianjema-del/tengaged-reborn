# Referencias y decisiones de Hunger V77

Se utiliza el texto de la wiki pegado por el usuario y la página pública de reglas de Regaged, revisada en esta sesión. No se atribuyen a la wiki contenidos que no se hayan podido leer.

Fuente aportada: https://tengagedspain.fandom.com/es/wiki/Hunger_Games_(Juego)
Referencia pública contrastada: https://regaged.com/game/cmve0e49o03wgka4hosnmxzxc

| Regla | Decisión para nuevas ediciones |
|---|---|
| 30 participantes, hasta diez en Cornucopia | Conservado |
| Vida de 0 a 100 | Conservado |
| Empate de duelo | Gana atacante, según el texto de la wiki |
| Duración | Ocho horas de duelo, según la wiki; ediciones anteriores conservan seis |
| Experiencia por rival | Primera lucha con ese rival; dos al atacante ganador, una al defensor |
| Armas del eliminado | Se transfieren usos restantes si el vencedor no tiene arma |
| Flechas | Diez al inicio; quince almacenadas; dianas disponibles durante combate |
| Patrocinio | Cinco por edición; +10 salud o +5 flechas; 15/50/100 T$ por destinatario |
| Tickets | Cinco al vencedor; un ticket paga un patrocinio |
| Modo Lobo | Adaptación explícita: diez minutos cada seis horas; la wiki no fija intervalos |
| Arbustos | Adaptación explícita: nueva búsqueda y posiciones compartidas cada cuatro horas |
| Flechas y acierto | Se conserva la probabilidad existente; la wiki no da una fórmula exacta de acierto |
| Huida | Permitida antes de confirmar el resultado; se conserva el guardado automático. No se añade una ventana para cancelar una puntuación ya guardada |
| Patrocinadores y ganador | Se conservan los premios de karma/T$ del proyecto y se añaden tickets; no se reparte el dinero gastado por espectadores como un bote |
| Final de edición | Archivo persistente y siguiente sala automática, conservando acceso al resultado anterior |

Las ediciones en curso mantienen su reglamento. Se conserva el motor de diez minijuegos compartidos con Casting. No se ha afirmado una réplica visual exacta ni compatibilidad táctil completa sin pruebas de dispositivo.
