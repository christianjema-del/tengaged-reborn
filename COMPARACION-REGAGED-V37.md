# Comparación con Regaged · V37

Se revisaron sus páginas públicas de Comunidad, Juegos, Grupos y Blogs, además de la ayuda pública. La referencia sirve para estructuras y comportamientos, no para importar usuarios, conversaciones o partidas de Regaged.

| Apartado | Estado de Tengaged Reborn V37 |
|---|---|
| Portada | Conserva la portada existente y añade grupos, blogs destacados y acceso a partidas propias. No es idéntica píxel por píxel. |
| Cabecera | Mantiene el orden solicitado de Comunidad, Minijuegos, Blogs, Juegos, Hall of Fame, Mafias, Diseños y Tiendas; añade accesos a jugadores, grupos, preguntas, ayuda y correo. |
| Perfil y avatar | Conserva las funciones y correcciones anteriores; añade correo y Pregúntame. |
| Correo | Implementación propia con privacidad por remitente/destinatario, lectura y bloqueo. No se copiaron mensajes de Regaged. |
| Blogs | Añade votos ±1, comentarios, paginación y ventana de tres días. No replica ponderaciones por nivel, menciones ni premios de clasificación. |
| Grupos | Añade directorio, admisión, foro, encuestas y galería. No incorpora todavía un motor de realities organizado por anfitriones. |
| Últimos mensajes | Muestra los comentarios públicos reales de las partidas propias de esta web. |
| Tiendas | Conserva ciclos de 48 horas y cinco escaparates. No sustituye esas reglas por el ciclo semanal de Regaged. |
| Mafias | Conserva creación, afiliación y solicitudes existentes. Elecciones, estrellas y otras reglas de Regaged siguen pendientes. |
| Minijuegos | Conserva los diez juegos, rankings e integración con Casting anteriores. |
| Formatos de juego | Mantiene Casting y Hunger Games. Fastings, Frookies, Rookies clásico, Survivor y The Duel no se han implementado aquí. |
| Stars | No se presenta como jugable ni se añade una simulación ficticia. |
| Pantallas privadas de referencia | La revisión automática bloqueó la apertura del perfil privado. No se inspeccionó el correo de esa cuenta. |

No se afirma paridad completa ni se presentan apartados pendientes como si funcionaran.
