# V7 · Perfil clásico y Mafia

Versión completa con el bloque Mafia encima de Amigos, sin el bloque Perfil. Ajustes de cabecera, estadísticas, fecha de registro, biografía, paginación numérica de juegos, esferas de resultados, blog y actividad compactos. Se conservan el editor de avatar al pulsar el retrato y el botón Editar de la biografía.

Mafia muestra que el usuario todavía no pertenece a ninguna: no existe aún un sistema de creación o afiliación. Las amistades y el chat mantienen sus datos y permisos.

Descomprime en Descargas y publica desde V7:

```
cd ~/Downloads/Tengaged-Reborn-V7-PERFIL-Y-MAFIA
ls profile.html wrangler.toml
npx wrangler pages deploy . --project-name tengaged-reborns
```

Recarga con ⌘ + Mayús + R.
