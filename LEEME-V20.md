# V20 · Formato de avatar compatible con diseños de Regaged

- El render principal de avatar utiliza lienzo SVG 200 × 230, con una composición común para los diseños y el probador.
- El editor muestra la proporción correcta y se conservan los ajustes guardados.
- El perfil vuelve a mostrar la imagen real del avatar (incluyendo prendas equipadas) al cancelar la previsualización de avatar clásico.
- No cambia el catálogo de diseños, tiendas, saldos ni rankings.

**Limitación:** es una adaptación del formato y las capas; NO reproduce todavía de forma exacta el arte base de Regaged. Para ello hacen falta referencias visuales claras del avatar sin equipamiento y/o recursos originales. Los JPG de 200x200 proporcionados contienen fondos recortados y no equivalen al PNG transparente de 200x230 requerido para vestirse con precisión.
